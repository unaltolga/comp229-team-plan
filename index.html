      How to open your pull request

      The GitHub mark (10 points) needs a commit from every member, so each of us has one small PR. Commit with your own GitHub account so it counts for you, and never commit .env.

      git clone https://github.com/Yosuke-cell/COMP229_Booking_System_Application.git
cd COMP229_Booking_System_Application
git checkout -b your-branch-name
# make your change
git add .
git commit -m "Describe the change in a few words"
git push -u origin your-branch-name
      1. On GitHub, open the repo and press Compare & pull request.
      2. Base is main. Add Yosuke-cell as reviewer, then Create pull request.
      3. Post the PR link in the chat.
